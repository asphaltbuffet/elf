## [0.4.0] - 2026-06-28

### Added

- Runners are defined by plugin system instead of being built-in
- Added 'runners install' subcommand to provide go and python runners
- Added a runner for bash solutions [#51]
- Added rust runner [#52]
- Added new timeout functionality for 'test', 'solve', and 'benchmark'; default of 2m can be overridden by '--timeout'/'-t' flag [#49]
- Visualize command available for Python and Go runners to create extra solution output files

### Changed

- Bump pelletier/go-toml v2.3.1 to v2.4.0
- Expanded downloader output to show added/skipped/replaced files
- Analyze subcommand enchancement for year vs day graphs
- Analysis graphs use Okabe–Ito CVD-safe palette
- Single exercise analysis graph focused on language variability
- Improve output for 'test' and 'solve'

### Fixed

- Cleanup phase removes wrapper directory if it's empty
- Download failure will no longer write an empty input file.
- Protection against panic if benchmark data is missing "part-one"
- Fixed golang import mismatch between wrapper and runner
- Termination of runner no longer leaves orphaned subprocesses
- Colors in analyze graphs are visually unique with some effort to be CVD safe
- Visualize outdir determines absolute path [#154]
